A small deterministic Python program that writes one original fortune-cookie line for a software developer to /output/entry.txt. The line is about the log warnings we scroll past by day and the interest they charge at 3 a.m. — one short balanced sentence, no network, no randomness, no dependencies.

## Run it

```sh
python3 main.py
```
